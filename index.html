Abstract

Clustering e-waste lintas sumber foto.

Studi ini mencari 16 clusters e-waste dari 3.792 foto pada dataset BDC Satria Data 2026, tanpa memakai class labels saat clustering. Pipeline menggabungkan image embeddings dari SigLIP2-So400m, PE-Core-G, dan DINOv3-H+; CMRE mengurangi pengaruh photo source relatif terhadap object class, lalu SCMax menentukan cluster count. Pada dataset BDC, xsrc (cross-source consistency) naik dari 0,524 pada raw fusion menjadi 0,975 setelah CMRE. Pada dataset Shubha sebagai fresh test, xsrc mencapai 0,956. Metrik ini menunjukkan konsistensi cluster lintas photo source, bukan class accuracy; class labels hanya dipakai setelah clustering untuk evaluasi.

Buka arti xsrc, CMRE, OOD, dan istilah teknis lainnya
xsrc · cross-source consistency
xsrc menjawab: seberapa sering foto sekelas dari target source masuk ke cluster yang sama dengan foto reference source? Contoh untuk mouse: cari cluster yang paling banyak berisi citra produk dari dataset Kaan, lalu hitung berapa proporsi foto mouse dari dataset Custom Bangladeshi E-Waste yang masuk ke cluster itu. Ulangi untuk tiap object class di kedua dataset dan ambil rata-ratanya. Ini bukan class accuracy.
Purity
Proporsi foto di dalam cluster yang class label evaluasinya sama dengan label terbanyak di cluster itu. Purity dihitung setelah clustering; class labels tidak dipakai untuk membentuk cluster.
Cluster, K, dan seed
Cluster adalah grup foto yang dianggap mirip oleh model. K adalah jumlah cluster. Seed mengatur unsur acak pada satu run supaya hasilnya bisa diulang.
Image embedding, backbone, dan feature fusion
Image embedding adalah deretan angka yang merangkum ciri visual foto. Backbone adalah image encoder yang membuat embedding. Feature fusion menggabungkan embedding dari beberapa backbone; raw fusion adalah gabungan sebelum CMRE.
Vision-language, self-supervised, dan model yang dipakai
Vision-language model (VLM) belajar hubungan antara image dan text; studi ini hanya memakai image encoder-nya. Self-supervised berarti model belajar dari pola pada data tanpa class labels. SigLIP2-So400m dan PE-Core-G adalah backbone vision-language; DINOv3-H+ adalah backbone self-supervised.
CMRE · Cross-Model Residual Erasure
CMRE memprediksi embedding vision-language dari DINOv3 reference, lalu menekan residual directions utama, yaitu bagian yang masih berbeda dari prediksi. Tujuannya mengurangi pengaruh photo source relatif terhadap object class, bukan menghapus semua informasi source. Parameter r menyatakan jumlah residual directions yang ditekan.
SCMax dan Spectral clustering
Spectral clustering membuat cluster dari graph kemiripan antar-foto. SCMax memilih K tanpa class labels: tetangga terdekat digabung secara bertingkat, lalu dipilih tingkat yang paling konsisten antara embedding asli dan embedding yang diberi gangguan kecil (perturbation). Sembilan seed SCMax menghasilkan median K = 16.
INLP ×3
Iterative Nullspace Projection (INLP) adalah baseline yang menekan arah embedding yang bisa memprediksi gaya foto. Di studi ini INLP memakai proksi gaya berbasis piksel yang dirancang manual (white background × tiga kelompok resolusi, enam grup), bukan class labels. ×3 berarti INLP diterapkan pada masing-masing dari tiga image embeddings.
OOD · out-of-distribution
Foto yang berbeda dari cakupan dataset utama. OOD score hanya menandai kandidat untuk ditinjau; flag OOD tidak otomatis memastikan ada kategori baru.
kNN, centroid, dan threshold
k-nearest neighbors (kNN) mencari embedding foto yang paling dekat. Centroid adalah titik pusat cluster. Threshold adalah batas score untuk memberi flag; dashboard memakai percentile ke-95 jarak foto pada dataset BDC, yaitu nilai yang mencakup 95% jarak di data acuan.
PCA-32
Principal Component Analysis (PCA) merangkum embedding menjadi 32 dimensions. PCA-32 dipakai sebelum Spectral clustering dan saat menghitung jarak kNN pada OOD check.
t-SNE
t-distributed Stochastic Neighbor Embedding memproyeksikan embedding ke bidang 2D agar pola tetangga lokal terlihat. Jarak dan posisi pada peta hanya perkiraan, tidak bisa dibandingkan antar-peta, dan bukan label cluster.
AUROC
Area Under the Receiver Operating Characteristic curve. AUROC menilai seberapa baik OOD score menempatkan foto OOD di atas foto yang mirip dataset utama pada berbagai threshold. Nilai mendekati 1 berarti ranking lebih baik; ini bukan persentase prediksi yang benar.
Bootstrap CI 95%
Confidence interval 95% adalah rentang ketidakpastian metrik dari banyak pengambilan ulang (resample) foto. Whisker pada grafik menunjukkan rentang ini bila tersedia.
Jaccard stability dan cluster membership
Jaccard mengukur seberapa banyak cluster membership yang sama pada beberapa bootstrap run, dari 0 sampai 1. Nilai lebih tinggi berarti foto lebih konsisten mendapat cluster assignment yang sama. Acuan 0,85 bukan uji signifikansi.
pHash dan Hamming distance
Perceptual hash (pHash) merangkum pola visual foto untuk mencari near-duplicates. Hamming distance menghitung perbedaan antar-hash; batas ≤ 6 dipakai untuk menandai foto duplikat.
Ridge regression dan R²
Ridge regression memprediksi embedding vision-language dari DINOv3 reference. R² menunjukkan seberapa dekat prediksi dengan nilai aktual; ini bukan clustering score atau class accuracy.
TTA · test-time augmentation
Foto diproses dalam bentuk asli dan horizontal flip. Kedua image embeddings dirata-ratakan agar representasi tidak bergantung pada arah foto.
ARI dan silhouette score
Adjusted Rand Index (ARI) membandingkan dua cluster assignments; 1 berarti sama, sekitar 0 berarti kesepakatan setara tebakan acak. Silhouette score menilai apakah foto lebih dekat dengan cluster-nya sendiri daripada cluster lain; rentangnya −1 sampai 1.
K-Means, Ward, dan GMM
Alternatif algoritma clustering yang dipakai sebagai pembanding. GMM adalah Gaussian Mixture Model, yang memperkirakan beberapa kelompok distribusi pada data.
DECMCV
Dual-Encoder Contrastive Learning with Multi-Clustering Voting adalah metode pembanding untuk klasifikasi sampah. Protokolnya menjalankan K-Means, Ward, dan BIRCH, lalu hanya mempertahankan foto yang disepakati ketiganya. Di dashboard, xsrc DECMCV dihitung pada semua foto; coverage menunjukkan porsi foto yang disepakati ketiga algoritma (81%). Lihat paper DECMCV.
Crop dan domain
Crop adalah potongan gambar yang berfokus pada objek. Domain menunjukkan konteks foto; pada dataset Office-Home, Product berisi citra produk dan Real World berisi foto dalam konteks keseharian.
WEEE, Small IT, dan B3
WEEE adalah singkatan dari Waste Electrical and Electronic Equipment, istilah untuk limbah perangkat listrik dan elektronik. WEEE 6 bernama Small IT and Telecom equipment. B3 berarti bahan berbahaya dan beracun.

Data

Delapan dataset dan perannya.

Cluster hanya dibentuk dari dataset BDC. Tujuh dataset lain dipakai setelah clustering untuk evaluasi: konsistensi lintas photo source, deteksi OOD, dan perpindahan domain.

Input clustering · 3.792 foto

Dataset BDC Satria Data

3.604 foto latih setelah deduplikasi ditambah 188 foto e-waste dari data uji. Label nama berkas tersedia untuk 2.331 foto dalam 10 class dan hanya dipakai untuk evaluasi. Lima di antaranya (baterai, keyboard, ponsel, mouse, PCB) juga ada di dataset Kaan dan dataset Custom Bangladeshi E-Waste, sehingga dipakai untuk xsrc.

Acuan xsrc · 1.794 citra produk

Dataset Kaan · Waste Classification

Menjadi sumber acuan: foto dari source lain dinilai berdasarkan cluster mayoritas pada dataset Kaan untuk class yang sama di lima kelas dataset BDC.

Target xsrc · 480 foto objek berlatar beragam

Dataset Custom Bangladeshi E-Waste

Foto objek dengan latar dan pencahayaan beragam menjadi sumber target, untuk mengukur apakah object class yang sama tetap masuk cluster yang sama meski gaya fotonya berbeda.

Evaluasi eksternal · 499 foto baterai

Dataset Karan · Garbage Classification

Sumber tambahan untuk memeriksa foto yang ditandai sebagai kandidat OOD (out-of-distribution).

Evaluasi OOD · 1.000 foto lapangan

Dataset GIZ E-Waste Database

Memuat benda yang belum ada pada dataset BDC. Contoh menonjol yang ditandai adalah AC, kulkas, dan kompresor.

Benchmark pengembangan · 1.751 crop

Dataset Iliev · Roboflow v44

Memiliki 69 source classes. xsrc memakai 10 class yang dapat dipetakan ke dataset BDC. Dataset ini juga dipakai memilih setelan OOD, jadi bukan fresh test.

Benchmark uji segar · 300 crop

Dataset Shubha

Lima kategori tersedia dengan 60 crop per kategori: keyboard, ponsel, mouse, remote, dan headphone. Tiga class pertama sepadan dengan dataset BDC; dua lainnya menguji OOD.

Benchmark lintas domain · 2.917 foto

Dataset Office-Home

Memakai 20 class terpilih dari domain Product dan Real World. Dataset ini menguji konsistensi saat tampilan bergeser dari citra produk ke foto dalam konteks keseharian.

Hasil

Perbandingan hasil pada empat dataset.

xsrc (cross-source consistency) merangkum seberapa sering foto dari dua photo source dengan object class yang sama masuk ke cluster yang sama. Nilainya dirata-ratakan pada class yang tersedia di kedua source. Untuk dataset BDC, reference source adalah dataset Kaan dan target source adalah dataset Custom Bangladeshi E-Waste. Purity mengukur kecocokan class label dengan label mayoritas cluster; keduanya dihitung setelah clustering, bukan sebagai training input.

Panel xsrc per metode merangkum dataset BDC (5 shared classes), dataset Iliev (10), dataset Shubha (3), dan dataset Office-Home (20). Untuk xsrc dataset BDC, dataset Kaan menjadi sumber acuan dan dataset Custom Bangladeshi E-Waste sumber target; dataset Karan dan dataset GIZ ditampilkan pada evaluasi source/OOD. Bandingkan metode di dalam panel masing-masing, bukan sebagai ranking lintas dataset. Semua panel memakai sumbu yang sama, 0,3–1,0, sehingga posisi titik bisa dibandingkan antarpanel; bootstrap CI 95% ditampilkan bila tersedia.

xsrc menurut metode dan dataset

Titik cokelat = CMRE; titik abu-abu = pembanding. Sumbu dimulai dari 0,3, bukan nol, agar selisih antarmetode terbaca; nilai terendah adalah 0,356. Whisker pada CMRE = bootstrap CI 95%; dataset Office-Home tidak memiliki interval.

Uji ketahanan

Sensitivitas terhadap parameter dan algoritma.

Sembilan seed SCMax memilih K antara 13 dan 19 (median 16). Stabilitas bootstrap tidak menunjuk satu K sebagai pemenang; K = 16 dipakai sebagai partisi utama dan K = 13 sebagai ringkasan kasar.

Pilihan cluster count K

xsrc dan purity pada dataset BDC; titik di bawah sumbu = sembilan pilihan SCMax. Sumbu nilai 0,4–1,0.

xsrcpurity BDC

Parameter r pada CMRE

xsrc menurut jumlah arah residu yang dihapus (sumbu r logaritmik). Nilai r = 16–64 berada pada plateau; r = 64 berasal dari aturan tanpa label (50% varians residu, batas 64 arah), bukan dipilih dari grafik ini.

Algoritma clustering, K = 16

xsrc pada representasi dan K yang sama. Batang mulai dari nol.

Pemeriksaan setelah partisi final dibekukan

Tidak ada pemeriksaan di bawah ini yang mengubah K, r, atau metode. Tujuannya menguji apakah klaim bertahan.

Metode clustering terbaru pada fitur yang sama

xsrc pada dataset BDC dengan CMRE features dan K = 16 yang sama; rata-rata 3 seed. DECMCV hanya memberi cluster assignment pada sebagian foto.

Model acuan CMRE, dipilih tanpa label

Diurutkan menurut R² ridge: seberapa baik acuan memprediksi embedding VLM, dihitung tanpa label. Batang = xsrc BDC setelah CMRE.

Bootstrap berpasangan: selisih xsrc usulan dikurangi pembanding

2.000 ulangan pada foto yang sama. Interval yang memuat nol berarti tidak berbeda nyata: CMRE setara INLP, tetapi tanpa proksi gaya.
